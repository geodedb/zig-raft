# raft Documentation

## Overview

A standalone Raft consensus library in Zig 0.15.1+. Implements the full Raft paper (Ongaro & Ousterhout, 2014) plus pre-vote, joint consensus membership changes, snapshotting, and chunked snapshot transfer.
